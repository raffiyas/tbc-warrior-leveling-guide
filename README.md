# TBC Warrior Fury Leveling Guide

Guía interactiva y no oficial para subir un Warrior Fury en WoW: The Burning Crusade Anniversary.

## Qué incluye

- Talentos nivel por nivel de 10 a 70.
- Enfoque Fury para leveo con flexibilidad para tankear dungeons.
- Rotación práctica y habilidades importantes del trainer.
- Consejos de armas, Rage, Defensive Stance y uso de escudo.
- Fuentes públicas de referencia, incluyendo Icy Veins, Wowhead y Warcraft Tavern.

## Sitio

El proyecto es una página estática sin dependencias: `index.html` contiene HTML, CSS y JavaScript. Esto permite publicarlo directamente con GitHub Pages sin npm ni build step.

## Publicar con GitHub Pages

1. Ve a **Settings → Pages** en este repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda los cambios.
5. GitHub publicará el sitio en `https://raffiyas.github.io/tbc-warrior-leveling-guide/`.
